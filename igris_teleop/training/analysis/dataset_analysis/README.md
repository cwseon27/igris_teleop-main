# training/analysis/dataset_analysis

수집 dataset의 joint/trajectory 통계를 분석하는 스크립트와 실행 메모를 둡니다.

- `CMD.md`: 분석 실행 명령 메모입니다.
- `joint_analysis.py`, `joint_analysis_0212.py`: joint statistics 분석입니다.
- `trajectory_analysis.py`: trajectory 기반 분석입니다.
- `outputs/`: 분석 결과 산출물이며 git 추적 대상이 아닙니다.

분석 결과를 공유할 때는 원본 dataset 경로와 분석 command를 함께 남깁니다.
